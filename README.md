# Magna International (magna-international)

Magna International is a Canadian global Tier 1 automotive supplier headquartered in Aurora, Ontario. Magna designs and manufactures vehicle bodies, chassis, exteriors, seating, powertrain, ADAS, electronics, mirrors, and complete vehicle assembly through its global operations.
